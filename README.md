# apstrahub-configpack-dc-probes

This repository contains an ApstraHub ConfigPack for DC BER and FEC interface counters probes, the BFD Session monitoring probe, and the EVPN Host Flapping monitoring probe.

ConfigPack documentation intended for end users is required to appear [here, in the README.md file in the `pack` directory](./pack/README.md). Check that file for details about this ConfigPack.
